# ml_project_ktok

単一の感染リスクを予測するのではなく時系列データとしての予測を目指す  
系列データのVAEを学習し，そのデコーダを使ってうまいこと何か出来ないかと模索したさいの残骸  
正直残しておく意味はないが，個人的には頑張っていたので残しておく
